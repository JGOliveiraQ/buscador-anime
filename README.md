Pesquisa de Animes
==================

Aplicação web responsiva para pesquisa e descoberta de animes.

Funcionalidades

- Exibição de animes populares
- Busca por título
- Filtros por tipo de anime
- Modal com informações detalhadas
- Layout responsivo para celular, tablet e computador
- Estados de carregamento, lista vazia e erro

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- AniList API

Como executar

Baixe ou clone o projeto e abra o arquivo index.html em um navegador. Também é possível usar a extensão Live Server no Visual Studio Code.

API utilizada

Os dados são obtidos pela AniList API, uma API pública com informações sobre animes.

Documentação: https://docs.anilist.co
